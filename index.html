1 · Single or Multichain Prediction

Inspect my structure prediction

Drop local outputs from AlphaFold-Multimer, AlphaFold 3, ColabFold, Boltz-1/2, Chai-1, OpenFold3, Protenix-v2, or ESMFold2. Compute iLIS, LIpDockQ, ipSAE, and actifpTM*, view synchronized PAE/LIS/cLIS maps and Mol* 3D, export ChimeraX/PyMOL scripts, or package a 1–5 MB shareable lightweight bundle.

Launch Prediction Analysis → Files stay in your browser
2 · Precomputed 50-Species Resource

Search a protein, variant, or motif

Explore precomputed interactome screens across human, model organisms, pathogens, and viruses in LIVIA Atlas. See cLIP binding-site clusters, tested negatives, AlphaMissense/pLDDT tracks, ortholog & paralog matrices, or query a specific residue/motif (e.g., R248, LXXLL).

Open LIVIA Atlas ↗ Batch pair lookup →
3 · Protein List → Complex Assembly

Assemble a hit list into complexes

Paste an AP-MS, BioID, or CRISPR hit list into LIVIA Atlas Network to recruit Steiner bridges, detect Leiden communities, inspect tested-negative matrices, and export multi-chain AlphaFold 3 JSON or Boltz-2 YAML inputs. Have your own lis.py CSV instead?

Open Atlas Network ↗ Own lis.py CSV? LIVIA PPI Network →
4 · Custom Screen Clustering

Cluster my lis.py screen by binding site

Drop a local lis.py CSV/XLSX table into cLIP (clustered Local Interaction Profiler) to group partners by shared cLIR contact footprints, separate competing vs. co-binding surfaces, identify cluster-specific mutant candidates, and recolor AlphaFold DB 3D models.

Launch cLIP → Resolves AFDB 3D & domains locally

GitHub

Source code, lis.py companion, and issue tracker.
Privacy & Browser: Tested on Chrome and Safari (macOS/iOS). All structure scoring runs locally in your browser; your files are never uploaded. To add gene names, domains, and reported interactions, selected pages query public APIs (UniProt, EBI BLAST, AlphaFold DB, MIST, BioGRID) — see what leaves your browser.
Reference Cutoffs: The top-ranked iLIS reference tiers (0.223 / 0.339 / 0.551; 10% / 5% / 1% empirical FPR) were calibrated on 5-model ColabFold AlphaFold-Multimer v2.3 (alphafold2_multimer_v3) heterodimers. For AlphaFold 3, Boltz, Chai-1, single-model runs, homodimers, and multichain assemblies, these thresholds serve as standardized reference tiers rather than strict empirical FPRs.
